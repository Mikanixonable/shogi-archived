# 将棋の囲い図鑑

先手の囲いを盤面で見比べるWebビューア。囲い・戦法・対局図・分類マップの4画面構成。

**公開ページ**: https://mikanixonable.github.io/shogi/

## 機能

- **囲い** — 居飛車12・振り飛車6、計18種の囲いを盤面と解説・出典付きで閲覧
- **戦法** — 12種の戦法を周期表形式で一覧し、局面を再生。囲いとの重ね合わせ表示にも対応
- **対局図** — 戦法同士の組み合わせを盤面で確認
- **分類マップ** — 囲い・戦法を系統ツリーで俯瞰
- 守りの利きヒートマップ、骨格線、立体駒（`?flat` で DOM 表示に切替）、明暗テーマ切替、URLハッシュによる表示状態の共有

## 使い方

ブラウザで公開ページを開くだけで使えます。インストールやログインは不要です。

- 上部のセグメントで「囲い / 戦法 / 対局図 / 分類マップ」を切替
- 左の一覧から項目を選択（←→↑↓キーでも移動可）
- 右上の設定アイコンで駒の強調・利き表示・骨格線などを調整
- URL の `#` 以降に表示状態が入るので、そのまま共有できます

## 開発者向け

ビルド不要の静的サイトです。古典スクリプト構成のため `file://` 直開きでも動作します。

### 構成

| パス | 内容 |
| --- | --- |
| `castles.html` | エントリページ（`index.html` は GitHub Pages 用のリダイレクト） |
| `js/manifest.js` | スクリプト読込順の一元管理 |
| `js/data/` | 囲い・戦法・分類・出典のデータ |
| `js/core/` | 盤面モデル・利き計算・検証などのロジック |
| `js/ui/` `js/modes/` | 画面部品と各ビューのモード |
| `js/vendor/` | ベンダリングした Three.js（立体駒用） |
| `css/` | テーマ・レイアウト・盤面のスタイル |
| `tools/` | データ検証・UI チェックのスクリプト |
| `docs/` | 設計メモ |

### テスト

```sh
npm install
npm test       # データ検証 + 単体テスト + UI チェック
npm run check  # UI チェックのみ
npm run shots  # スクリーンショットのみ
```

UI チェックは playwright-core で実ブラウザを起動します（Node.js 20+）。システムの Chrome/Edge、または `npx playwright install chromium` で取得した headless shell を使用します。
